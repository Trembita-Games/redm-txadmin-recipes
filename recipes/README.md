Validate recipes in a clean txAdmin deployment directory before using them for a real server.

---

## Usage

Use the raw GitHub URL when loading a custom recipe in txAdmin.

Example format:

```txt
https://raw.githubusercontent.com/Trembita-Games/redm-txadmin-recipes/main/recipes/vanilla.yaml
```

After stable releases are available, prefer release tag URLs instead of `main`.
