# Troubleshooting

Troubleshooting guide for `redm-txadmin-recipes`.

---

## txAdmin Cannot Load Recipe

Check:

- recipe URL is reachable
- recipe file is valid YAML
- raw GitHub URL is used
- repository visibility is public
- there are no syntax errors in the recipe

For GitHub-hosted recipes, use a raw URL.

Example:

```txt
https://raw.githubusercontent.com/Trembita-Games/redm-txadmin-recipes/main/recipes/vanilla.yaml
```

For stable deployments, prefer release tags once available.

---

## Deployment Completes but Server Does Not Start

Check generated files:

```txt
server.cfg
permissions.cfg
resources/
```

Also check:

- license key is present
- endpoints are generated
- max clients value is generated
- required resources are present
- `set gamename rdr3` exists
- `sessionmanager-rdr3` is ensured

---

## Missing Resources

If server logs show missing resources such as:

```txt
Couldn't find resource mapmanager.
Couldn't find resource chat.
Couldn't find resource spawnmanager.
Couldn't find resource sessionmanager-rdr3.
```

The recipe likely did not install default Cfx.re resources correctly.

Check the txAdmin deployer output and confirm the `resources/` directory was created.

---

## License Key Issues

If server logs show:

```txt
This server does not have a license key specified.
```

Check that the recipe uses txAdmin license placeholders correctly.

The generated `server.cfg` should include a license key line generated by txAdmin.

---

## Public Networking

If server list checks fail or friends cannot connect, check:

- TCP `30120`
- UDP `30120`
- Windows Firewall
- VPS firewall/security group
- router port forwarding
- NAT/CG-NAT limitations

This is separate from recipe validation.

---

## Runtime Data

Do not commit runtime files generated by txAdmin.

Examples:

```txt
txData/
cache/
logs/
server/
resources/
```
