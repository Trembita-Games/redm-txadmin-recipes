# Troubleshooting

Troubleshooting guide for `redm-txadmin-recipes`.

---

## txAdmin Cannot Load Recipe

Check:

- recipe URL is reachable
- recipe file is valid YAML
- raw GitHub URL is used
- repository visibility is public
- there are no syntax errors in the recipe
- the URL points to the correct recipe path

For GitHub-hosted recipes, use a raw URL.

Vanilla recipe example:

```txt
https://raw.githubusercontent.com/Trembita-Games/redm-txadmin-recipes/main/recipes/vanilla/recipe.yaml
```

Trembita recipe example:

```txt
https://raw.githubusercontent.com/Trembita-Games/redm-txadmin-recipes/main/recipes/trembita/recipe.yaml
```

For stable deployments, prefer release tags.

Example:

```txt
https://raw.githubusercontent.com/Trembita-Games/redm-txadmin-recipes/v0.1.9/recipes/vanilla/recipe.yaml
```

---

## Recipe URL Uses an Old Layout

If txAdmin reports errors for a recipe path like:

```txt
recipes/vanilla.yaml
recipes/trembita.yaml
```

the URL is using the old layout.

Use the current layout instead:

```txt
recipes/vanilla/recipe.yaml
recipes/trembita/recipe.yaml
```

---

## Invalid `write_file` Parameters

If txAdmin shows an error like:

```txt
Recipe error: [task1:write_file] invalid parameters
```

check the recipe file for invalid `write_file` parameters.

For `write_file`, use:

```yaml
- action: write_file
  file: ./README.txt
  data: |
    Example content
```

Do not use:

```yaml
content: |
```

Do not use unsupported template parameters unless txAdmin explicitly supports them.

---

## Deployment Completes but Server Does Not Start

Check generated files:

```txt
server.cfg
permissions.cfg
secrets.cfg
resources/
```

Also check:

- license key is present in `secrets.cfg`
- Steam Web API key is present in `secrets.cfg` if provided
- endpoints are generated in `server.cfg`
- max clients value is generated in `server.cfg`
- admin principals are generated in `server.cfg`
- required resources are present
- `set gamename rdr3` exists
- `sessionmanager-rdr3` is ensured

---

## Missing Resources

If server logs show missing resources such as:

```txt
Couldn't find resource mapmanager.
Couldn't find resource chat.
Couldn't find resource spawnmanager.
Couldn't find resource sessionmanager-rdr3.
```

The recipe likely did not install default Cfx.re resources correctly.

Check the txAdmin deployer output and confirm the `resources/` directory was created.

For the vanilla recipe, default Cfx.re resources should be downloaded from upstream Cfx.re/CitizenFX server data.

---

## License Key Issues

If server logs show:

```txt
This server does not have a license key specified.
```

check that `server.cfg` executes:

```cfg
exec secrets.cfg
```

Then check that `secrets.cfg` exists and contains:

```cfg
sv_licenseKey "YOUR_KEY"
```

If `secrets.cfg` still contains the unresolved placeholder:

```cfg
sv_licenseKey "{{svLicense}}"
```

then variable replacement did not run.

The recipe must include:

```yaml
- action: replace_string
  mode: all_vars
  file: ./secrets.cfg
```

---

## Invalid License Key Format

If server logs show:

```txt
Could not authenticate server license key. Invalid key format specified.
```

check `secrets.cfg`.

The file must contain a full FXServer command:

```cfg
sv_licenseKey "YOUR_KEY"
```

It must not contain only the raw key:

```txt
cfxk_example_key
```

It must not contain an unresolved placeholder:

```cfg
sv_licenseKey "{{svLicense}}"
```

---

## Steam Web API Key

The shared secrets template contains:

```cfg
set steam_webApiKey "{{steam_webApiKey}}"
```

The recipe should define:

```yaml
variables:
  steam_webApiKey: ""
```

If Steam authentication is not needed, this can stay empty.

If Steam authentication is needed, provide a valid Steam Web API key during txAdmin deployment.

---

## Data Folder Name Is `unnamed_*.base`

If txAdmin generates a data folder like:

```txt
unnamed_12345.base
```

check recipe metadata.

The recipe should use:

```yaml
name: Trembita-RDR2
author: Trembita Games
description: Clean vanilla RedM/RDR2 txAdmin recipe
```

Do not use `$name`.

txAdmin uses the plain `name` field for the generated `.base` folder prefix.

---

## Public Networking

If server list checks fail or friends cannot connect, check:

- TCP `30120`
- UDP `30120`
- Windows Firewall
- VPS firewall/security group
- router port forwarding
- NAT/CG-NAT limitations

This is separate from recipe validation.

---

## Runtime Data

Do not commit runtime files generated by txAdmin.

Examples:

```txt
txData/
cache/
logs/
server/
resources/
```

---

## Release Tag Issues

If a recipe downloads this repository using a release tag:

```yaml
- action: download_github
  src: https://github.com/Trembita-Games/redm-txadmin-recipes
  ref: v0.1.5
  dest: ./temp/redm-txadmin-recipes
```

make sure the tag exists and contains the expected files.

If you update files after creating a tag, the tag will not change automatically.

Create a new patch release instead of changing an existing tag.
