# Templates

Configuration templates used by txAdmin recipes.

---

## Structure

```txt
templates/
├── vanilla/
│   ├── server.cfg
│   ├── permissions.cfg
│   └── secrets.cfg
└── vanilla-with-server-data/
    ├── server.cfg
    └── permissions.cfg
```

---

## Purpose

Templates keep recipe YAML files smaller and easier to read.

They also make server configuration easier to review separately from deployment logic.

---

## Vanilla Templates

The vanilla recipe uses:

```txt
templates/vanilla/server.cfg
templates/vanilla/permissions.cfg
templates/vanilla/secrets.cfg
```

`server.cfg` contains the main server configuration.

`permissions.cfg` contains base permission rules.

`secrets.cfg` contains deployment-specific secret values generated by txAdmin, including:

```cfg
sv_licenseKey "{{svLicense}}"
set steam_webApiKey "{{steam_webApiKey}}"
```

---

## Notes

Templates are intended for txAdmin recipe generation.

They are not the same as the Git-first configuration files in `redm-vanilla-template`.
